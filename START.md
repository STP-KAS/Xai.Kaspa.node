# Start here

Each person who uses this gets **their own** Grok Bot team (their sandbox, their node, their companions). Customize anything you want. If you mess it up, come back here for a **fresh start**.

## Fresh start / reset

Anytime: open this file again → new or existing **`kaspa bot`** → paste the block below → send.  
That reloads the runbook from GitHub and rebuilds the stack.

https://github.com/STP-KAS/Xai.Kaspa.node/blob/main/START.md

## Step 1
1. Create a **new Grok Bot agent** (or reuse yours)
2. Name it **`kaspa bot`**
3. Paste **only** the block below and send

**kaspa bot = only input.** Companions are read-only for day-to-day use (you can still ask Grok to change them anytime — this is your team).
