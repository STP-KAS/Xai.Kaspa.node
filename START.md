# Start here

This sets up **your** Kaspa bot team on **your** Grok Bot Linux sandbox.

The node runs there — **not** on your phone or PC.

## Do this

1. Create a **new Grok Bot agent**.
2. Name it **`kaspa bot`**.
3. Paste the block below into the **kaspa bot** agent you just created.
4. Send it.
5. **Let it do its job. Do not interfere.**
6. **kaspa bot** will report when everything is running and ready to go.
7. Then customize, improve, and refine — send those tasks to **kaspa bot**.

Price talk stays forbidden (see `what is kaspa?`).

This paste is **mainnet only**. Testnet-10 node + miner is a **separate** agent named **tn10 bot**: https://github.com/STP-KAS/groks-wallet/blob/main/START-TN10.md — do not paste that here.
